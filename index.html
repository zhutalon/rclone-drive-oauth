Personal Google Drive Mount

A personal desktop configuration that uses rclone to access Google Drive files from the owner's computer.

After the owner authorizes access through Google, the software can list, read, upload, modify, rename, and delete Drive files as requested by the owner. It stores authorization credentials and a file cache locally on the owner's computer. This is a personal configuration and is not an official Google or rclone service.
