Privacy policy

Last updated: November 7, 2026.

Personal Google Drive Mount is a personal configuration of rclone operated by its owner on the owner's computer. It is intended for the owner's own use.

Google data accessed and used

With the Google account owner's authorization, rclone accesses Google Drive file names, folder information, metadata and file contents. It uses that access to list, read, download, create, upload, change, rename and delete files or folders when requested by the owner.

Storage and sharing

rclone communicates with Google Drive through Google's API. OAuth credentials are stored in the owner's local rclone configuration. File data may be stored in a local cache, and operation logs may contain file paths and error information. The operator does not run a separate server to receive Drive file contents. Google processes requests according to its own policies, and access to the computer and its local files is controlled by the owner.

Retention and control

Drive files remain in the Google account until changed or deleted by its owner. Locally cached data, logs and credentials remain on the computer according to its configuration and can be removed by its owner. The owner can revoke this application's access from Google Account settings under third-party connections.

Google API Services User Data Policy

The use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including its Limited Use requirements.
